AASHRITH'S HAPPY LEARNING WORLD — PWA

1. Extract this ZIP file.
2. In your public GitHub repository, upload ALL these files, keeping the icons folder:
   index.html
   manifest.webmanifest
   service-worker.js
   icons/icon-192.png
   icons/icon-512.png
3. Go to Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/ in Chrome on the Android tablet.
5. Chrome menu (three dots) > Install app or Add to Home screen.
6. Open once while connected to internet to cache the application for offline use.

Notes:
- GitHub Pages provides HTTPS, required for PWA installation.
- Voice is provided by the tablet's installed speech synthesis voices and may vary or
  need a downloaded offline English voice pack to work without internet.
- Updates: upload changed files and increment the CACHE version in service-worker.js.
- A GitHub repository public to everyone should not include private photos or information.
